# TextSpace

A local-first, paginated word processor built with **Uno Platform**, **C#**, and **SkiaSharp**. A familiar ribbon, editable paper, and independently reusable document, editing, layout, rendering, and UI libraries.

**Development release — not Microsoft Word and not full Word compatibility.** TextSpace is an independent implementation. Microsoft Word and Microsoft 365 are trademarks of Microsoft. No Microsoft source code, branding assets, or proprietary fonts are included.

The initial implementation is being validated. Architecture, feature coverage, build instructions, and deployment information are maintained in this repository.
